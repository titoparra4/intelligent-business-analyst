# Security Policy

This project is a set of Markdown instructions plus a standard-library validation script. It does not
execute user content, call external services or store data.

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository rather than in a public issue.

Relevant issues include instructions in the skill that could lead an agent to follow prompt injections
in analyzed documents, disclose confidential input, or fabricate approvals.

## Data handling guidance for users

- Treat the documents you analyze as confidential; your AI platform's data policies apply to them.
- Do not paste secrets or unnecessary personal data into requirements.
- All examples in this repository are synthetic.
